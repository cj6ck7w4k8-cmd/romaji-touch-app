# 📱 ローマ字学習Webアプリ「ローマ字マスター」

## 再開後の初回公開版（2026-08-12）

再開時点の要件定義に合わせ、初回公開の対象をレベル1〜3（清音）に固定しています。ログイン・個人情報・音声は扱わず、端末内のLocalStorageだけで学習状況、星、最短タイム、解放状態を保存します。

- レベル1：清音を1行ずつ
- レベル2：隣接する2行
- レベル3：清音全体（じゅんばん／らんだむ）
- れんしゅう：3秒後のヒントと誤答時の正解強調
- ほんばん：ヒントなしで採点
- ひんと：右上から左方向へ並ぶ行別のローマ字一覧
- きろく：クリア数、星、最短タイム、確認付きリセット

促音・拗音・撥音（レベル4〜6）、コイン、ガチャ、ログインボーナス、クラウド同期は初回版の対象外です。詳しい再開判断と検証結果は、Second Brainの[[2026-08-12*ローマ字タッチアプリ再開ログ]]に記録しています。

## 📄 アプリ概要・仕様書

### 1. ひらがな表記ルール【最重要】
* 画面上の案内、ボタン、ステージ名、メッセージなど、**ユーザーが見る文字列はすべて「ひらがな（または数字）」**で表記します（漢字は一切使いません）。

---

### 2. レベル構成（全6レベル）

| レベル | レベルめい（ひらがな表示） | しゅつだい はんい | モード / しょうさい |
| :--- | :--- | :--- | :--- |
| **レベル1** | **1つずつ おぼえよう** | せいおん（あ行、か行…など 1つのグループ） | **【ふつう】** 最初からあそべる（5たく）<br>**【ダミーあり】** ふつうをクリアでかいほう（7たく程度） |
| **レベル2** | **2つ つづけて しょうぶ！** | せいおん（あ行＋か行…など 2つのグループ） | **【ふつう】** レベル1クリアでかいほう（10たく）<br>**【ダミーあり】** ふつうをクリアでかいほう（12たく程度） |
| **レベル3** | **ぜんぶの もじ（あ〜ん）** | せいおん（あ〜ん 全体） | **【ふつう】** 「あ」からじゅんばんに出題。きろくタイムあり<br>**【ランダム】** ふつうをノーミスクリアでかいほう。出題がランダム |
| **レベル4** | **むずかしい もじ（1つずつ）** | そくおん・ようおん・はつおん（きゃ・きゅ・きょ / っ / ん など 1つのグループ） | レベル1とおなじ（「ふつう」と「ダミーあり」） |
| **レベル5** | **むずかしい もじ（2つ つづけて）** | そくおん・ようおん・はつおん（2つのグループ） | レベル2とおなじ（「ふつう」と「ダミーあり」） |
| **レベル6** | **むずかしい もじ（ぜんぶ）** | そくおん・ようおん・はつおん 全体 | レベル3とおなじ（「ふつう」と「ランダム」）。きろくタイムあり |

---

### 3. ほし（評価）ときろくルール

* **レベル1・2・4・5**
  * **ふつうモード:** ノーミスのほし（きいろ）＋ スピードのほし（きいろ）
  * **ダミーありモード:** いろちがいのノーミスのほし（ピンク/にじいろ）＋ いろちがいのスピードのほし（ピンク/にじいろ）/ コイン増量
* **レベル3・6**
  * **スピードのほしは無し**。ただし、ノーミスでクリアしたときの**タイム（秒数）を記録**。
  * **ふつうモード:** ノーミスのほし（きいろ）
  * **ランダムモード:** いろちがいのノーミスのほし（ピンク/にじいろ）/ コイン増量

---

### 4. モード構成・学習サポート
* **ローマ字ずかん:** いつでも確認できる「あいうえお表」。タップで音や対応ローマ字を表示。
* **れんしゅうモード:** ペナルティなし。3秒経過で母音（a, i, u, e, o）の色分け表示。ミス時に正解ボタンが光る（お助けヒント）。
* **ほんばんモード:** ヒントなし。「ほし」や「コイン」を獲得できる実力試しモード。

---

### 5. 継続＆モチベーション向上機能
* **がんばりスタンプカレンダー ＆ ログインボーナス:** 1日1回プレイでスタンプ付与。3日連続ログインで50コイン、7日連続ログインで100コイン！
* **ガチャ ＆ ごほうびシール帳:** 50コインで1回ガチャを回し、当たった可愛いシールを一覧で鑑賞できる。
* **コンボ演出:** 連続正解で「2れんぞく！」「3れんぞく！」などの演出と紙吹雪。
* **データ保存:** LocalStorageを使用し、星・コイン・シール・ログイン履歴をすべてブラウザに自動保持。
