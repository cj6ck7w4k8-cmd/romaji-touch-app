# ローマ字マスター

低学年の子どもが、ひらがなを見てローマ字をタップで学ぶWebアプリです。キーボード入力やログインは必要ありません。

公開サイト：<https://romaji-touch-app.vercel.app/>

## いま公開されている機能

### 学習

| レベル | 学ぶ内容 | 取り組み方 |
| --- | --- | --- |
| レベル1 | 清音を1行ずつ | あ行、か行のように1行ずつ選ぶ |
| レベル2 | 清音のとなり合う2行 | あ・か、か・さのように2行を続けて学ぶ |
| レベル3 | 清音ぜんぶ | じゅんばん、またはランダムで学ぶ |
| レベル4 | 濁音・半濁音を1行ずつ | が行、ざ行、だ行、ば行、ぱ行を選ぶ |
| レベル5 | 清音の拗音を1行ずつ | きゃ行、しゃ行、ちゃ行などを選ぶ |
| レベル6 | 濁音・半濁音の拗音を1行ずつ | ぎゃ行、じゃ行、びゃ行、ぴゃ行を選ぶ |
| レベル7 | これまでに学んだ文字 | 30問をランダムに出題する |
| レベル8 | 短いことば | 促音をふくむことばから、毎回10問をランダムに出題する |

- **れんしゅう**：3秒後に答えを表示する。記録・解放の条件にはならない。
- **ほんばん**：答えを見ずに取り組む。クリア、バッジ、最短タイム、次のレベルの解放を記録する。
- **こたえを みる**：その問題の正解と、次に押す選択肢を表示する。使った問題は「まちがえなし」にならない。
- **いちらん**：レベル1〜6の文字をローマ字と見比べられる表。横長の画面では、あいうえおを左から右へ読める並びにする。

ローマ字は日本式です。たとえば、`し=si`、`ち=ti`、`つ=tu`、`ふ=hu`、`じ=zi`、`しゃ=sya`です。レベル1の「わ行」には`ん=n`も入っています。

### 記録とメダル

- レベル1・2：クリア、まちがえなし、はやさのバッジを記録する。
- レベル3：クリア、まちがえなし、最短タイムを記録する。
- レベル4〜8：クリア、まちがえなしのバッジを記録する。
- メダル：今あるバッジと最短タイムから、10個の長い目標を自動で判定する。
- 記録はこの端末・このブラウザのLocalStorageへ保存する。端末やブラウザが変わると引き継がれない。
- 「きろくを リセット」で、クリア、バッジ、タイム、メダルをまとめて消せる。

### 画面と操作

- 画面の案内は、ひらがな・カタカナ・数字を中心に表示する。ローマ字は学習内容として表示する。
- 1画面では、次に押す主なボタンが分かることを優先する。
- 問題を選ぶ画面は「レベルをえらぶ」→「もんだいをえらぶ」の順に分けている。
- 横長の端末では、主要な操作がスクロールなしで収まるようにしている。記録が多いときは、記録をページに分けて表示する。

## これから検討すること

学習内容の追加や記録の条件は、実際に使う子どもの様子を見ながら検討します。現時点で、次に実装する内容は決めていません。

- 長音など、まだ扱っていない表記の学習
- 出題数、解放条件、バッジ・メダル条件の見直し
- ダミーあり、コイン、ガチャ、ログインボーナス、クラウド同期の必要性

## 開発

```bash
pnpm install
pnpm dev
```

本番用のファイルを作るときは、次を実行します。

```bash
pnpm run build
```

Vercelでは、このリポジトリの`main`ブランチを公開し、ビルドコマンドに`pnpm run build`、公開するフォルダに`dist`を設定しています。
